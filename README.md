# 微信小店运营分析自动化

本项目用于本地采集微信小店后台数据，分析订单、退款、商品表现和人群适配，并生成投放建议报告。

## 当前状态

- 依赖只写入清单，尚未安装。
- 采集选择器尚未用真实微信小店后台校准。
- 本轮按用户要求未启动浏览器、未启动服务、未运行测试。
- 当前代码是本地自动化 MVP 骨架，后续运行前需要先完成依赖安装和选择器校准。

当前目标是本地多店铺 AI 分析版：

1. 复用本机浏览器登录态访问微信小店后台。
2. 自动识别/配置多个店铺，切换店铺、选择时间范围并导出订单/商品/罗盘等数据。
3. 导入 Excel/CSV，统一清洗为结构化数据。
4. 计算订单量、退款量、退款率、客单价、商品成交贡献、评价、资金、投放等扩展指标。
5. 构建脱敏 AI 分析 payload，生成单店和多店报告骨架。
6. 提供本地 FastAPI 管理后台 API 骨架。

当前已覆盖的本地链路：

- Node + Playwright 采集骨架：负责登录后页面导出、店铺发现占位、多店铺任务和下载保存。
- Python 导入链路：支持 Excel/CSV 导入、字段映射、warning、店铺名快照和 SQLite 入库。
- 分析链路：支持订单、退款、商品表现、人群/罗盘洞察的初步指标。
- 报告链路：输出 Markdown、summary CSV、products CSV、audience CSV。
- 数据模型：预留评价、店铺日报、商品日报、流量来源、资金流水、投放、采集任务、AI 报告等标准表。
- AI 分析：生成聚合脱敏 payload 和 OpenAI dry-run 请求结构，不会真实调用 API。
- 本地 API：提供 `/health`、`/shops`、`/tasks`、`/reports`、`/exports` 等 FastAPI 骨架。

详细进度见 `PROGRESS.md`。
