# 指标口径

## 订单指标

| 指标 | 口径 |
|---|---|
| 总订单量 | 指定周期内创建的订单数 |
| 有效成交订单量 | 已付款、已完成且未全额退款的订单 |
| 退款订单量 | 发生全额或部分退款的订单 |
| 退款占比 | 退款订单量 / 有效成交订单量 |
| GMV | 指定周期订单支付金额 |
| 净成交额 | 支付金额 - 退款金额 |
| 客单价 | 净成交额 / 有效成交订单量 |

## 店铺日概览指标

| 指标 | 口径 |
|---|---|
| 数据行数 | `shop_daily` 中落入分析周期的行数，按 `stat_date` 过滤 |
| 日期范围 | 落入周期的最早/最晚 `stat_date` |
| 访客数、浏览量 | 周期内对应日指标求和；微信小店“商品曝光人数”不会映射为访客数或浏览量 |
| 商品曝光人数、商品点击人数、商品点击次数 | 周期内对应日指标求和，来自 `exposure_user_count`、`click_user_count`、`click_count` |
| 下单金额、下单订单数、下单人数 | 周期内对应日指标求和，来自 `order_amount`、`order_submit_count`、`order_user_count` |
| 成交订单数、成交人数、成交件数 | 周期内对应日指标求和，来自 `order_count`、`buyer_count`、`sold_quantity` |
| 成交金额、退款金额 | 周期内对应日金额求和，来自 `payment_amount`、`refund_amount` |
| 净成交额 | 成交金额 - 退款金额 |
| 点击率 | 优先按 商品点击人数 / 商品曝光人数 计算；无点击人数但有点击次数时按 商品点击次数 / 商品曝光人数 兜底 |
| 点击成交率（次数） | 优先按 成交订单数 / 商品点击次数 计算；无法计算时保留导入的“点击成交率（次数）”日均值 `avg_click_conversion_rate` |
| 转化率 | 优先按 支付买家数 / 访客数 计算；无买家数时按 成交订单数 / 访客数 计算；无法计算时保留导入转化率的日均值 `avg_conversion_rate` |
| 退款率 | 优先按 退款金额 / 成交金额 计算；无法计算时保留导入退款率的日均值 `avg_refund_rate` |
| 日均指标 | 周期汇总值 / 有效统计日期数；无有效日期时按行数兜底 |

注意：`shop_daily_metrics`/`overview_daily_metrics` 是店铺日表口径，不回填 `order_metrics`。因此订单表为空时，订单指标仍可为 0，但店铺日概览会反映真实导入的日汇总数据。

## 商品指标

| 指标 | 口径 |
|---|---|
| 商品成交订单数 | 包含该商品的有效成交订单数 |
| 商品退款订单数 | 包含该商品且发生退款的订单数 |
| 商品退款率 | 商品退款订单数 / 商品成交订单数 |
| 商品成交贡献 | 商品净成交额 / 全店净成交额 |

## 人群指标

| 指标 | 口径 |
|---|---|
| 主力客群 | 有成交、成交金额或转化率的人群标签，按转化率、成交金额、成交数、访客数排序 |
| 潜力客群 | 有访客但未识别成交的人群标签，用于小预算测试 |
| 风险客群 | 退款率不低于 20%，且有一定成交基础的人群标签 |
| 人群适配 | 结合商品、类目、人群维度、标签、访客、成交、转化率和退款率输出 |

注意：当前人群洞察按店铺全量已导入数据计算，尚未按订单分析周期过滤。采集类型 `compass` 的导出文件导入后映射为 `audience_insights`。
